I've been using a lot of AI recently. Especially coding this blog out, setting up the initial part of the rewiring connections page. In Robot Reboot: Vision, I tried to build things without using AI as much as I could, but then right after that class, I don't know, lately I've been using it a whole lot.  
What does that mean for the practice that I want to build? Where should I be using AI? Not in generating art, of course, but what about stuff like this, like setting up the webpage, etc. I don't know how to decide where my morals lie here. I don't want to forget the coding skills that I built so carefully during undergrad, and the manner in which I enjoyed using python. I still do.  

When I made 'Trash!' I coded everything, and I figured it out. I miss that, the challenges of debugging. Even though the project wasn't perfect. I can't tell how much I should chase this perfectionism, let projects fall by the wayside, but stick to my stance on AI. I feel like it's this constant debate I'm having about AI, technology, and perhaps pivoting out of ITP? Find more things outside of it, and then settle into academia? It's not as research-focused as I'd want it to be. I'm trying to make it the best way I can, but people don't critique work enough, and then when rejection hits, it feels all so fresh.
